Политика конфиденциальности

Настоящая Политика конфиденциальности действует в отношении всей информации, которую приложение «Самопознание» (далее – «Приложение») может получить о пользователе во время использования.

1. Какие данные мы собираем

  • Идентификатор пользователя ВКонтакте (VK ID): используется для авторизации.
  • Текстовые и голосовые сообщения: используются для работы ИИ-психолога.
  • Эмоциональные оценки: для построения динамики настроения.

2. Цели обработки данных

  • Предоставление доступа к функционалу Приложения.
  • Улучшение качества работы ИИ-психолога.
  • Ведение статистики для улучшения сервиса.

3. Условия обработки и хранения данных

Обработка персональных данных осуществляется в соответствии с Федеральным законом № 152-ФЗ «О персональных данных». Все данные хранятся на серверах, расположенных на территории Российской Федерации.

Пользователь может запросить удаление своих данных, направив запрос на почту: s.khudonogov@mail.ru.

4. Передача данных третьим лицам

Приложение не передает персональные данные пользователей третьим лицам, за исключением случаев, предусмотренных законодательством РФ.

5. Согласие на обработку данных

Используя Приложение, пользователь дает свое согласие на обработку своих персональных данных в соответствии с настоящей Политикой.
